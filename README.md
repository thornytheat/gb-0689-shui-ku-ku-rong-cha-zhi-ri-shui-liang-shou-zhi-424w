# 水库库容插值与日水量收支

使用者：水库调度数据员。采信水位流量日志，复核日库容变化与入出库偏差。

核心规则：同库主备站合并为一条连续水位；单调水位库容曲线分段线性插值；流量梯形积分；缺口超限不插补，日边界拆分且收支误差显式归因。

## 启动

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

浏览器访问 http://localhost:18203 。首页已装载脏样例，可编辑CSV与参数后运行，也可上传文件。七个导航分别对应业务步骤。

## 模块

- M1 测站采信：采信水位流量与来源，识别主站/备站与所属水库，入口 `/m/1`、`GET/POST /api/m1`。
- M2 曲线校核：校验曲线、测次冲突，隔离备站气泡并合并同库主备站，入口 `/m/2`、`GET/POST /api/m2`。
- M3 流量积分：梯形积分并定位缺口，入口 `/m/3`、`GET/POST /api/m3`。
- M4 库容换算：按曲线分段换算库容，入口 `/m/4`、`GET/POST /api/m4`。
- M5 日收支：每库一条跨午夜日账，逐段标注水位/流量来源与接续锚点，入口 `/m/5`、`GET/POST /api/m5`。
- M6 异常复核：按缺测优先裁决超差，入口 `/m/6`、`GET/POST /api/m6`。
- M7 重算留痕：核对总积分与重算水位，入口 `/m/7`、`GET/POST /api/m7`。

## 演示与复核

1. 运行默认样例，核查隔离原因与业务合计。
2. 载入 `two_station.csv`（主站缺测三点、备站有风壅偏差与两处气泡），
   M5 应只出一条按库汇总的日账，水位来源拆分显示主站/备站时长。
3. 修改CSV单元格或参数并重跑，保留行号与输入摘要。
4. 在最后一步复核，旧版本提交返回409。
5. 证据CSV包含采信行和隔离行，重跑相同内容复用批次、不新增日账；生成失败保留旧版。

## 数据与目录

`app/modules/` 按业务切分；`sample_data/` 为UTF-8 BOM、GB18030及干净/脏/主备两站样例；`tests/` 含规则与端到端测试。SQLite保存运行与复核，命名卷records保留重启后的记录。若需从头开始，可先停止服务并在确认不再需要记录后删除该项目records卷。

## 定义与边界

库容曲线采用线性分段，不作范围外推；流量与水位相邻点间线性变化。同库合并以主站水位为锚，备站只补主站缺测，风壅偏差按中位数估计。未建蒸发降雨及地下渗漏模型，收支差保留待人工归因。

详细字段、计算定义与原因码见 `docs/DATA-DICTIONARY.md`，回归证据见 `docs/DEPTH.md`。
